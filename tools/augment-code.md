## What Is Collected

- Code context for completions, chat and agents
- Codebase indexing data (stored to power the context engine)
- Usage Data: "performance and usage data generated or collected through or in connection with" use of the service (Community Terms 1.5)
- Device data (OS, browser type, IP) and online activity data (per privacy policy)
- Google Analytics (named in privacy policy)
- Account / organization data

**Training (Community Terms v1.9):** as a condition of access, users grant Augment the right to use Customer Code, Output and Usage Data to train AI models, and Augment may use, share, license or sell anonymized versions of them.

## What Is NOT Collected

- Per Community Terms 1.5, Usage Data does not include Customer Code or Output
- Augment's security page states it never trains on customers' proprietary code (applies to the terms governing those customers)

## How to Fully Opt Out

1. **Plan/terms:** review which terms apply -- the Community Terms permit training; paid/enterprise agreements may differ
2. **Google Analytics:** use Google's opt-out browser add-on
3. **Usage data:** no documented opt-out
4. **Network-level:** blocking Augment endpoints breaks the product

## Red Flags

- Community Terms (v1.9) make a grant to use Customer Code, Output and Usage Data to train AI models a condition of access, and allow sharing/licensing/selling anonymized versions
- Security page states Augment never trains on customers' proprietary code -- the two statements apply to different terms and should be read together
- Codebase indexing means significant code exposure
- No documented way to disable usage metrics
- Closed source -- cannot verify data handling claims

**Notes:** Training posture depends on plan/terms: the Community Terms of Service permit training on Customer Code, Output and Usage Data; Augment's security page says it never trains on customers' proprietary code. The previous 'training is opt-in' note could not be confirmed and has been removed.

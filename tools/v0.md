## What Is Collected

- All prompts and instructions, generated code, iteration history
- Account info, session/usage analytics, browser/device info, sharing events, error reports

**Model training (since March 2026):**
- Hobby accounts, including v0 Free/Premium on a Hobby account: opted in by default
- Paid Pro: opted out by default; Enterprise: excluded
- When opted in, training data includes code, Vercel agent chats (including v0 chats), build/deployment telemetry, build errors and aggregate traffic stats

## What Is NOT Collected

- Per Vercel, personal information, account details, environment variables and API keys are anonymized/redacted before training use
- Enterprise data is excluded from training

## How to Fully Opt Out

1. **Training opt-out:** Vercel dashboard > Team Settings > **Data Preferences** (not Account Settings); individual projects via Project Settings
2. **Upgrade:** paid Pro is opted out by default
3. **CLI only:** `vercel telemetry disable` affects the Vercel CLI, not v0

## Red Flags

- Since March 2026, Hobby accounts (incl. v0 Free/Premium on a Hobby account) are opted in to AI model training by default; training data includes code and v0 chats
- All prompts and generated code processed and stored on Vercel servers
- Closed source
- Prompts may contain proprietary design specifications

**Notes:** v0 moved from v0.dev to v0.app. Per Vercel, personal information, account details, environment variables and API keys are anonymized/redacted before training use.

## What Is Collected

- When active: code snippets in logs (30-day retention), issue descriptions and PR context, PostHog usage analytics (tickets, comments, PRs merged), repository embeddings, account/org data

## What Is NOT Collected

- Per the privacy page, data was not sold to third parties

## How to Fully Opt Out

Service discontinued. Uninstall the Sweep GitHub App from your organization and request deletion from Sweep if you used it.

## Red Flags

- 30-day code snippet retention
- PostHog analytics sent to third-party servers
- Service archived/discontinued -- unclear what happened to stored data
- No documented opt-out was available when active
- Data retention after service shutdown is unclear
